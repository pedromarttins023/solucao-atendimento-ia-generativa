# Protótipo de Assistente Virtual com IA Generativa

Documentação e arquitetura de um protótipo de assistente virtual inteligente voltado para automação de atendimento e suporte.

## Estrutura da Solução
- Detalhamento e contextualização de instruções (System Prompts)
- Regras e diretrizes para proteção de dados sensíveis e privacidade
- Passo a passo completo para replicação do projeto
